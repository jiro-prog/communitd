# 参照ディレクトリ (claude の --add-dir)

> 作業ディレクトリの外を読ませる口と、それが読み書き両方を開けること。
> 入口は [README](../../README.md)、導入手順は [SETUP.md](../../SETUP.md)。

作業ディレクトリの外を読ませたいときは、チャンネル設定に `claudeAddDirs` を書く。
claude ランタイムの `--add-dir` へそのまま渡る (codex ランタイムは対象外)。

```json
"channels": {
  "my-project": { "cwd": "C:/path/to/your/project", "claudeAddDirs": ["../design-notes"] }
}
```

- 相対パスは **`cwd` 基準**で絶対パスへ正規化する。重複と `cwd` 自身は落とす
- **`--add-dir` は読み書きの両方を開ける。読取専用にはできない。** 参照のつもりで足した
  ディレクトリにも書けてしまうので、境界は「書けないこと」ではなく
  **「書いたら `git status` の差分に出ること」**で担保する — 足すのは git 管理下のツリーに限ること
  (ターン末尾の 📋 差分は `cwd` のものだけなので、追加ディレクトリ側の変更はそこには出ない)
- 実在確認はしない (`cwd` と同じ扱い)。綴り違いは claude 側の起動エラーとしてスレッドに出る。
  型不正 (配列でない・空文字混じり) は起動時に落とす
- `.env` を持つツリーや秘密の置き場を足さないこと。子プロセスの env からトークンは除いているが、
  **ファイルとして読める場所は読まれる**
